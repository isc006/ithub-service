Ы# Note Service — Сервис заметок

## Описание проекта

Описание проекта в ветке fix/conflict-demo.
## Основные возможности

- Создание заметок.
- Просмотр списка заметок.
- Редактирование заметок.
- Удаление заметок.

## Цель проекта

Изучение Git, GitHub, ветвления, коммитов и командной разработки.

## Технологии

- Git
- GitHub
- Markdown

## Структура проекта

- `README.md` — описание проекта.
- `project-notes.md` — заметки о проектировании.
- `api-plan.md` — план API.
- `git-conflict.md` — описание разрешённого конфликта.
